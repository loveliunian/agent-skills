## 用户管理

### 1. 查询用户列表

**请求**:
```http
GET /users?page=1&size=20&name=张三
Authorization: Bearer {token}
```

**参数**:
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码，默认 1 |
| size | int | 否 | 每页数量，默认 20 |
| name | string | 否 | 用户名（模糊查询） |
| status | string | 否 | 状态（active/inactive） |

**响应**:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 100,
    "page": 1,
    "size": 20,
    "items": [
      {
        "id": 1,
        "name": "张三",
        "email": "zhangsan@example.com",
        "status": "active",
        "roles": ["USER"],
        "createdAt": "2026-09-15T10:00:00Z"
      }
    ]
  }
}
```

---

### 2. 创建用户

**请求**:
```http
POST /users
Authorization: Bearer {token}
Content-Type: application/json

{
  "name": "张三",
  "email": "zhangsan@example.com",
  "password": "Password123!",
  "roleIds": [1, 2]
}
```

**参数**:
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | 是 | 用户名，2-50 字符 |
| email | string | 是 | 邮箱，唯一 |
| password | string | 是 | 密码，8-20 字符，需包含大小写字母和数字 |
| roleIds | array | 否 | 角色 ID 列表 |

**响应**:
```json
{
  "code": 200,
  "message": "创建成功",
  "data": {
    "id": 1,
    "name": "张三",
    "email": "zhangsan@example.com",
    "status": "active"
  }
}
```

**错误码**:
| 错误码 | 说明 |
|--------|------|
| 400 | 参数错误 |
| 409 | 邮箱已存在 |
| 403 | 权限不足 |

```markdown
## 常见问题（FAQ）

### Q1: 忘记密码怎么办？

A: 
1. 点击登录页面的"忘记密码"
2. 输入注册邮箱
3. 查收邮件，点击重置链接
4. 设置新密码

### Q2: 为什么无法删除用户？

A: 可能原因：
- 您没有删除权限（需要管理员角色）
- 用户有未完成的订单
- 用户是最后一个管理员

### Q3: 如何批量导入用户？

A: 
1. 点击"导入用户"按钮
2. 下载模板文件
3. 按模板格式填写用户信息
4. 上传 Excel 文件
5. 确认导入
```

```bash
# 复制配置模板
cp .env.example .env
```

`.env` 文件内容:
```bash
# 数据库配置
DB_HOST=mysql

DB_USER=root

REDIS_HOST=redis
```

## 生产环境部署

### 1. 使用 Nginx 反向代理

```nginx
# /etc/nginx/sites-available/governance

server {
    listen 80;
    server_name example.com;

    # 前端
    location / {
        proxy_pass http://localhost:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # 后端 API
    location /api {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```
