# Phase 6c: 端到端测试（End-to-End Testing）

## 目标

- 验证完整的用户场景（前端 + 后端 + 数据库）
- 模拟真实用户操作流程
- 验证跨模块、跨服务的集成
- 确保关键业务流程可用

## 进入条件

- [ ] P6a 单元测试已完成（覆盖率 ≥ 80%）
- [ ] P6b 集成测试已完成（覆盖率 ≥ 60%）
- [ ] 前端和后端都已部署到测试环境
- [ ] 测试数据已准备

---

## E2E 测试特点

### E2E vs 集成测试

| 维度 | 集成测试 | E2E 测试 |
|------|---------|---------|
| **测试范围** | 后端 API（Controller → Service → Repository） | 前端 + 后端 + 数据库 + 中间件 |
| **用户视角** | 开发者视角（接口调用） | 最终用户视角（页面操作） |
| **环境** | 单体应用 + Mock 数据库 | 完整环境（Docker 容器） |
| **测试工具** | MockMvc / RestTemplate | Playwright / Selenium / Cypress |
| **运行速度** | 快（秒级） | 慢（分钟级） |
| **稳定性** | 高 | 相对低（网络、浏览器、异步） |
| **覆盖率目标** | 60% | 95%（核心流程） |

---

## E2E 测试分类

### 1. 关键业务流程（Critical Path）

**定义**: 用户最常用、业务价值最高的流程

**覆盖率目标**: 100%

**示例**:
- 用户注册 → 登录 → 浏览商品 → 下单 → 支付
- 管理员登录 → 审批订单 → 发货
- 用户登录 → 查看订单 → 申请退款

---

### 2. 跨模块流程（Cross-Module）

**定义**: 涉及多个模块协作的流程

**示例**:
- 用户管理 + 权限管理: 创建用户 → 分配角色 → 验证权限
- 订单 + 库存 + 支付: 下单 → 扣减库存 → 支付 → 发货

---

### 3. 异常场景（Exception Path）

**定义**: 用户操作失败或异常的场景

**示例**:
- 登录失败: 密码错误、账号未激活、账号被锁定
- 下单失败: 库存不足、地址不存在、支付超时
- 权限不足: 普通用户访问管理员功能

---

## 技术选型

### 1. Playwright（推荐，现代化）

**优点**:
- 支持多浏览器（Chrome / Firefox / Safari）
- 自动等待元素可见（减少 flaky 测试）
- 支持截图和视频录制
- 支持并行执行

**安装**:
```bash
npm init playwright@latest
```

**示例**:
```javascript
// tests/e2e/user-login.spec.js
import { test, expect } from '@playwright/test';

test('用户登录成功', async ({ page }) => {
  // 1. 访问登录页
  await page.goto('http://localhost:3000/login');
  
  // 2. 填写用户名
  await page.fill('input[name="username"]', 'testuser');
  
  // 3. 填写密码
  await page.fill('input[name="password"]', 'password123');
  
  // 4. 点击登录按钮
  await page.click('button[type="submit"]');
  
  // 5. 等待跳转到首页
  await page.waitForURL('http://localhost:3000/dashboard');
  
  // 6. 验证用户名显示
  await expect(page.locator('.user-name')).toHaveText('testuser');
});

test('用户登录失败 - 密码错误', async ({ page }) => {
  await page.goto('http://localhost:3000/login');
  
  await page.fill('input[name="username"]', 'testuser');
  await page.fill('input[name="password"]', 'wrongpassword');
  await page.click('button[type="submit"]');
  
  // 验证错误提示
  await expect(page.locator('.error-message')).toHaveText('用户名或密码错误');
  
  // 验证未跳转
  expect(page.url()).toBe('http://localhost:3000/login');
});
```

### 2. Cypress（推荐，前端友好）

**优点**:
- 专为前端设计，API 简洁
- 实时重载（修改代码即时看到效果）
- 强大的调试工具
- 自动截图和视频

**安装**:
```bash
npm install cypress --save-dev
npx cypress open
```

**示例**:
```javascript
// cypress/e2e/user-management.cy.js
describe('用户管理', () => {
  beforeEach(() => {
    // 每个测试前登录
    cy.login('admin', 'admin123');
  });
  
  it('创建用户', () => {
    cy.visit('/users');
    
    // 点击"新增用户"按钮
    cy.contains('新增用户').click();
    
    // 填写表单
    cy.get('input[name="name"]').type('张三');
    cy.get('input[name="email"]').type('zhangsan@example.com');
    cy.get('select[name="role"]').select('USER');
    
    // 提交
    cy.contains('保存').click();
    
    // 验证成功提示
    cy.contains('创建成功').should('be.visible');
    
    // 验证用户出现在列表中
    cy.contains('张三').should('be.visible');
  });
  
  it('删除用户', () => {
    cy.visit('/users');
    
    // 找到第一个用户的删除按钮
    cy.get('table tbody tr').first().find('.delete-btn').click();
    
    // 确认删除
    cy.contains('确定').click();
    
    // 验证成功提示
    cy.contains('删除成功').should('be.visible');
  });
});

// cypress/support/commands.js
Cypress.Commands.add('login', (username, password) => {
  cy.session([username, password], () => {
    cy.visit('/login');
    cy.get('input[name="username"]').type(username);
    cy.get('input[name="password"]').type(password);
    cy.get('button[type="submit"]').click();
    cy.url().should('include', '/dashboard');
  });
});
```

### 3. Selenium（传统，兼容性好）

**适用场景**: 需要兼容老旧浏览器

**示例（Java + Selenium）**:
```java
@Test
public void testUserLogin() {
    WebDriver driver = new ChromeDriver();
    
    try {
        // 1. 访问登录页
        driver.get("http://localhost:3000/login");
        
        // 2. 填写表单
        driver.findElement(By.name("username")).sendKeys("testuser");
        driver.findElement(By.name("password")).sendKeys("password123");
        
        // 3. 点击登录
        driver.findElement(By.cssSelector("button[type='submit']")).click();
        
        // 4. 等待跳转
        WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
        wait.until(ExpectedConditions.urlContains("/dashboard"));
        
        // 5. 验证用户名
        String userName = driver.findElement(By.className("user-name")).getText();
        assertEquals("testuser", userName);
    } finally {
        driver.quit();
    }
}
```

## E2E 测试最佳实践

### 1. 使用 Page Object Model（POM）

**目的**: 提高代码复用性和可维护性

**示例**:
```javascript
// pages/LoginPage.js
class LoginPage {
  constructor(page) {
    this.page = page;
    this.usernameInput = page.locator('input[name="username"]');
    this.passwordInput = page.locator('input[name="password"]');
    this.submitButton = page.locator('button[type="submit"]');
    this.errorMessage = page.locator('.error-message');
  }
  
  async goto() {
    await this.page.goto('http://localhost:3000/login');
  }
  
  async login(username, password) {
    await this.usernameInput.fill(username);
    await this.passwordInput.fill(password);
    await this.submitButton.click();
  }
  
  async getErrorMessage() {
    return await this.errorMessage.textContent();
  }
}

// tests/login.spec.js
test('用户登录', async ({ page }) => {
  const loginPage = new LoginPage(page);
  
  await loginPage.goto();
  await loginPage.login('testuser', 'password123');
  
  await page.waitForURL('**/dashboard');
  expect(page.url()).toContain('/dashboard');
});
```

### 2. 测试数据隔离

**原则**: 每个测试用例使用独立的测试数据

```javascript
// 方式 1: 使用 API 创建测试数据
test('用户编辑', async ({ page, request }) => {
  // 通过 API 创建测试用户
  const response = await request.post('/api/users', {
    data: {
      name: '测试用户',
      email: `test-${Date.now()}@example.com`
    }
  });
  const user = await response.json();
  
  // 在页面中编辑用户
  await page.goto(`/users/${user.id}/edit`);
  await page.fill('input[name="name"]', '张三');
  await page.click('button[type="submit"]');
  
  // 验证
  await expect(page.locator('.success-message')).toBeVisible();
});

// 方式 2: 使用数据库脚本初始化
beforeEach(async () => {
  // 清空数据库
  await execSync('psql -d test_db -c "TRUNCATE users CASCADE"');
  
  // 插入基础数据
  await execSync('psql -d test_db -f tests/fixtures/users.sql');
});
```

### 3. 等待策略

**避免硬编码延迟** (`sleep(5000)`)

```javascript
// ❌ 不好的做法
await page.click('button');
await page.waitForTimeout(5000);  // 硬编码延迟

// ✅ 好的做法 - 等待元素出现
await page.click('button');
await page.waitForSelector('.success-message');

// ✅ 好的做法 - 等待网络请求完成
await Promise.all([
  page.waitForResponse(response => response.url().includes('/api/users')),
  page.click('button')
]);

// ✅ 好的做法 - 等待 URL 变化
await page.click('button');
await page.waitForURL('**/dashboard');
```

## E2E 测试环境

### 1. Docker Compose 环境（推荐）

**目的**: 保证测试环境一致性

```yaml
# docker-compose.e2e.yml
version: '3.8'

services:
  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: root
      MYSQL_DATABASE: test_db
    ports:
      - "3307:3306"
  
  redis:
    image: redis:7
    ports:
      - "6380:6379"
  
  backend:
    build: ./backend
    environment:
      SPRING_PROFILES_ACTIVE: e2e
      DB_HOST: mysql
      REDIS_HOST: redis
    ports:
      - "8080:8080"
    depends_on:
      - mysql
      - redis
  
  frontend:
    build: ./frontend
    environment:
      API_URL: http://backend:8080
    ports:
      - "3000:3000"
    depends_on:
      - backend
```

**启动测试环境**:
```bash
# 启动环境
docker-compose -f docker-compose.e2e.yml up -d

# 等待服务就绪
./scripts/wait-for-services.sh

# 执行 E2E 测试
npx playwright test

# 清理环境
docker-compose -f docker-compose.e2e.yml down -v
```

### 示例 1: 用户注册到登录完整流程

```javascript
// tests/e2e/user-registration-flow.spec.js
import { test, expect } from '@playwright/test';

test.describe('用户注册到登录完整流程', () => {
  const email = `test-${Date.now()}@example.com`;
  
  test('E2E-001: 完整流程', async ({ page }) => {
    // Step 1: 访问首页
    await page.goto('http://localhost:3000');
    
    // Step 2: 点击"注册"按钮
    await page.click('a[href="/register"]');
    await expect(page).toHaveURL('**/register');
    
    // Step 3: 填写注册表单
    await page.fill('input[name="name"]', '张三');
    await page.fill('input[name="email"]', email);
    await page.fill('input[name="password"]', 'Password123!');
    await page.fill('input[name="confirmPassword"]', 'Password123!');
    
    // Step 4: 提交注册
    await page.click('button[type="submit"]');
    
    // Step 5: 验证注册成功提示
    await expect(page.locator('.success-message')).toHaveText('注册成功，请登录');
    
    // Step 6: 跳转到登录页
    await expect(page).toHaveURL('**/login');
    
    // Step 7: 使用注册的账号登录
    await page.fill('input[name="email"]', email);
    await page.fill('input[name="password"]', 'Password123!');
    await page.click('button[type="submit"]');
    
    // Step 8: 验证登录成功
    await expect(page).toHaveURL('**/dashboard');
    await expect(page.locator('.user-name')).toHaveText('张三');
  });
});
```

// tests/e2e/admin-user-management.spec.js
test.describe('管理员用户管理', () => {
  test.beforeEach(async ({ page }) => {
    // 管理员登录
    await page.goto('http://localhost:3000/login');
    await page.fill('input[name="email"]', 'admin@example.com');

    await page.waitForURL('**/dashboard');

  test('E2E-002: 创建用户并分配角色', async ({ page }) => {

    await expect(page).toHaveURL('**/users');

## 经验教训应用

### L-P3-003: 真实容器 E2E 必须在 P6 执行

**问题**: MockMvc 全绿，但真实 Docker 容器启动时 Spring Context 初始化失败

**解决方案**:
1. P6c 阶段必须在真实容器中执行 E2E 测试
2. 使用 Docker Compose 搭建与生产一致的测试环境
3. 容器启动失败 = P6c gate 阻断

---

## 反模式

❌ **只测试 Happy Path**：忽略异常场景  
❌ **使用 MockMvc 代替 E2E**：无法发现真实环境问题  
❌ **测试用例相互依赖**：前一个失败导致后续全部失败  
❌ **硬编码延迟**：`sleep(5000)` 导致测试慢且不稳定  
❌ **不录制失败视频**：无法复现问题  
❌ **测试数据不清理**：数据残留影响下次测试
