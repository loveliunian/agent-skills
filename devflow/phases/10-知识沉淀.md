# Phase 10: 知识沉淀 (Knowledge Sharing)

> **P11 继承**：Postmortem (`commands/postmortem.md`) 直接复用本模板结构，只需在复盘总结基础上补充 §3 影响范围 + §5 5Why + §9 根因分析段。

## 目标

- 沉淀项目经验
- 分享技术成果
- 识别改进机会
- 避免重复踩坑

---

## 知识沉淀形式

| 形式 | 说明 | 产出 |
|------|------|------|
| **技术分享** | 团队内部分享 | 分享PPT/演示 |
| **复盘总结** | 项目回顾总结 | 复盘报告 |
| **技术博客** | 对外技术文章 | 博客文章 |
| **Wiki文档** | 知识库沉淀 | Wiki页面 |

---

## 技术分享模板

```markdown
# 技术分享: [主题]

## 分享信息
- **分享人**: 
- **分享日期**: 
- **分享时长**: 30分钟

## 分享内容

### 1. 背景
[为什么做这个项目/功能]

### 2. 技术方案
[采用的方案、架构设计]

### 3. 难点与解决方案
| 难点 | 解决方案 | 效果 |
|------|----------|------|
|      |          |      |

### 4. 踩坑记录
| 坑 | 表现 | 原因 | 解决 |
|----|------|------|------|
|    |      |      |      |

### 5. 最佳实践
[总结的经验教训]

### 6. Q&A
[常见问题及回答]

## 反馈收集
[团队反馈和改进建议]
```
