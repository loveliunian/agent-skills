## 语言总纲（v3.18.0）

> 本阶段全部文档（API/数据库/部署/运维/用户手册）的中文表达遵循 `concepts/中文文风规范.md`：
> 说人话——主谓宾完整、一句话一个主张、结论自己站着（表格只做佐证）、数字给单位和口径、
> 同一事物全文一个名字、不把工具/校验器内部机制写进面向读者的正文。

## API文档规范

### OpenAPI/Swagger格式

```yaml
openapi: 3.0.0
info:
  title: 用户服务API
  version: 1.0.0
paths:
  /api/users/{id}:
    get:
      summary: 获取用户信息
      parameters:
        - name: id
          in: path
          required: true
          schema:
            type: integer
      responses:
        '200':
          description: 成功
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/User'
```

### 必填字段

| 字段 | 说明 |
|------|------|
| 接口名称 | 清晰的中文描述 |
| 请求方法 | GET/POST/PUT/DELETE |
| 请求路径 | API路径 |
| 请求参数 | 参数名、类型、必填、说明 |
| 请求示例 | JSON格式示例 |
| 响应参数 | 字段说明、类型 |
| 响应示例 | 成功/失败示例 |
| 错误码 | 可能的错误及处理方式 |
