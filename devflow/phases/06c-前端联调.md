# Phase 6c: 前端联调

## 目标

完成前后端API对接，验证数据交互正确，实现完整的功能闭环。

---

## 联调前准备

### 后端检查清单

- [ ] API文档已完成 (Swagger/OpenAPI)
- [ ] 所有接口已实现并测试通过
- [ ] 接口返回格式统一
- [ ] 错误码文档完善
- [ ] CORS配置正确

### 前端检查清单

- [ ] API调用层封装完成
- [ ] 请求/响应拦截器配置
- [ ] 错误处理机制完善
- [ ] 页面组件开发完成

---

## 联调流程

```dot
digraph integration {
    rankdir=LR;
    
    backend [label="后端开发\n完成接口", shape=box];
    api_doc [label="API文档\nSwagger", shape=box];
    frontend [label="前端开发\nMock数据", shape=box];
    connect [label="接口对接\n联调", shape=box];
    test [label="功能验证\nBug修复", shape=box];
    
    backend -> api_doc;
    api_doc -> frontend;
    frontend -> connect;
    connect -> test;
}
```

### Step 1: 后端启动服务

```bash
# 启动后端服务
cd backend
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

### Step 2: 验证Swagger文档

```bash
# 访问Swagger UI
open http://localhost:8080/swagger-ui.html
```

### Step 3: 逐接口联调

按优先级逐个接口验证：

```
联调顺序:
1. 简单接口（GET单条、DELETE）先调
2. 复杂接口（POST、PUT）后调
3. 核心业务接口优先调
4. 边缘接口最后调
```

---

## 联调问题排查

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 跨域错误 | CORS未配置 | 后端配置CORS或网关代理 |
| 401未授权 | Token未传递 | 检查请求头Authorization |
| 404接口不存在 | 路径错误 | 对照Swagger检查路径 |
| 500服务器错误 | 后端异常 | 查看后端日志 |
| 400参数错误 | 字段格式不对 | 对照API文档检查字段 |

## Red Flags 🚩

以下情况必须停止并汇报：

| 红旗 | 问题 | 正确做法 |
|------|------|----------|
| 接口定义不一致 | 不对照文档 | 必须对照Swagger |
| 忽略错误处理 | 只处理成功 | 必须处理所有错误 |
| 数据格式混乱 | 前后端格式不一 | 必须统一格式 |
| 问题不记录 | 只在群里说 | 必须记录文档 |

---

## 常见问题处理

| 问题 | 解决方案 |
|------|----------|
| 跨域错误 | 后端配置CORS |
| 数据类型不一致 | 统一使用JSON类型 |
| 日期格式不一致 | 统一使用ISO 8601 |
| 枚举值不一致 | 统一枚举定义 |

---

## 关键原则

1. **文档驱动** - 按Swagger文档对接
2. **问题记录** - 所有问题记录在案
3. **及时沟通** - 问题及时反馈
4. **完整验证** - 覆盖正向和异常场景
