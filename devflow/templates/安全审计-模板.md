# 安全审计报告 - {feature}

## 字段要点（正本见 schema）

| 字段 | 约束 |
|------|------|
| write_operations_total | 写操作端点总数（POST/PUT/DELETE/PATCH）；0 表示本 feature 无写操作 |
| preauthorize_coverage | 授权注解（@PreAuthorize 或等价适配器）覆盖率 0-100；存在缺口必须逐条登记发现 |
| findings[] | 发现清单（id/title/severity/status/evidence）；P0/P1 必须 CLOSED 或 WAIVED 且绑定豁免依据；无发现须 zero_results 声明 |
| waiver_file | 豁免声明文件；存在 WAIVED 发现时必填 |
| report_path | 报告路径；须真实存在并与渲染产物一致 |

## 渲染结构（产物章节正本）

- 覆盖概览
- Gate 机器字段（由 df_render 从 JSON 派生，人工勿改）

## 通过条件

- 管线校验通过；`p3_security_perf_gate.sh` 通过（P0/P1 无 OPEN、覆盖率缺口有发现兜底）。
