## 1. 权限码命名规范（手维护）

### 1.1 三段格式

```
{module}:{resource}:{action}
```

| 段位 | 取值 | 说明 |
|---|---|---|
| 模块 | 业务模块英文小写 | 与 §2 扫描结果一致 |
| 资源 | 资源对象英文小写 | 与业务对象对应 |
| 动作 | 标准动词（§1.2） | 操作类型 |

### 1.2 标准动作清单

```

toggle / enable / disable / export / import / audit
```
