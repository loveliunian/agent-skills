# 详设章节锚点索引（skill 自动化用）


> 
> **目的**：详设章节 ↔ skill 自动化脚本的契约
> **场景**：P4通过冻结验收ID和实现证据路径精确匹配；章节号不是契约。

---

## 1. p4 兼容性策略

### 1.1 自动生成的索引（必读）

| 索引 | 路径 | 来源 |
|---|---|---|
| 表索引 | `INDEX-表.md` | 汇总各 M-* 详设数据模型节（完整版 §2.2 / 分文档 §2.3） |
| 接口索引 | `INDEX-接口.md` | 汇总各 M-* 详设接口设计节（完整版 §3 / 分文档 §5） |

### 1.2 内容正则（**兼容现有详设**）

- 数据模型（完整版 §2.2 / 分文档 §2.3）→ 抓 `gov_*` / `sys_*` / `t_*` 等表前缀
- 接口设计（完整版 §3 / 分文档 §5）→ 抓 `(GET|POST|PUT|DELETE|PATCH) /api/...` 路径
- 关键流程（完整版 §6 / 分文档 §4）→ 抓 `关键流程` / `关键规则` / `业务流程` 关键词

P4不依赖固定章节命名；P2 Gate校验语义结构，P4校验原子验收ID集合。

## 2. 数据模型识别正则

```regex
^\s*\|\s*([a-z][a-z0-9_]*)\s*\|          # Markdown 表格行
|^\s*CREATE\s+TABLE\s+([a-z_][a-z0-9_]*)  # SQL 建表
```

## 3. 接口设计识别正则

```regex
(GET|POST|PUT|DELETE|PATCH)\s+\`?/api/[^\s\`]+`?
```

## 4. 关键流程识别关键词

```regex
关键流程|关键规则|业务流程|状态转换|异常处理
```

## 5. 跨详设冲突

| 类型 | 优先级 | 说明 |
|---|---|---|
| INTERFACE.md 已存在 | INDEX-接口.md 优先 | INDEX 是聚合源 |
| 表名冲突 | 按服务路由 | sys_* → org-service |
| 4 方言差异 | 自动扫描 | 见项目 ER 索引（如有） |
