# 性能审计报告 - {feature}

## 字段要点（正本见 schema）

| 字段 | 约束 |
|------|------|
| scenarios[] | 压测场景至少覆盖核心写路径与最重查询；每场景含 p95_ms / threshold_ms / status；任一非 PASS 即阻断 |
| nplus1_suspicious | N+1 可疑模式数（扫描口径与 Gate 一致）；>0 须在 conclusion 给出复核结论 |
| conclusion | 审计结论（N+1 复核、优化决定等） |
| report_path | 报告路径；须真实存在并与渲染产物逐字节一致 |

## 渲染结构（产物章节正本）

- 场景实测
- Gate 机器字段（由 df_render 从 JSON 派生，人工勿改；`p3` Gate 与 JSON 逐场景对账）

## 通过条件

- 管线校验通过；`p3_security_perf_gate.sh` 通过（无场景 FAIL、报告绑定一致）。
