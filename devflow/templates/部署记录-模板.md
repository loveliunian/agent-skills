### 本地端口预检（仅本地进程启动）

```bash
SERVICE="${SERVICE:-org-service}"
PORT="${PORT:-$(grep -E '^[[:space:]]*port:' "backend/$SERVICE/src/main/resources/application.yml" 2>/dev/null | grep -oE '[0-9]+' | head -1)}"
test -n "$PORT" || { echo "BLOCKED: 无法解析服务端口"; exit 1; }

# 本地启动前端口必须空闲；远程/Kubernetes 部署不执行本检查。
if command -v lsof >/dev/null 2>&1 && lsof -nP -iTCP:"$PORT" -sTCP:LISTEN >/dev/null 2>&1; then
  echo "BLOCKED: 端口 $PORT 已被占用"
  exit 1
fi
```

## 部署步骤

### 1. 数据库迁移

```bash
# 确认 Flyway 脚本
$ ls backend/<service>/src/main/resources/db/migration/postgresql/<module>/V<version>__*.sql

# 执行迁移
$ flyway -url=jdbc:postgresql://... -schemas=public migrate
```

**验证：**
```bash
$ curl -sS -o /dev/null -w "%{http_code}" "http://localhost:$PORT/actuator/health"
# 预期：200
```

### 2. 后端服务部署

```bash
# 打包
$ cd backend/<service> && mvn clean package -DskipTests

# 部署
$ kubectl apply -f deploy/<service>.yaml

# 检查滚动更新
$ kubectl rollout status deployment/<service>
```

**验证：**
```bash
$ curl -sS "http://localhost:$PORT/actuator/health"
{"status":"UP"}

$ curl -sS "http://localhost:$PORT/actuator/prometheus" | grep "{feature}"
# 预期：metrics 包含 feature 相关指标
```

### 3. 前端部署

```bash
# 打包
$ cd frontend && npm run build

# 部署
$ kubectl apply -f deploy/frontend.yaml
```

**验证：**
```bash
$ curl -sS -o /dev/null -w "%{http_code}" https://{domain}/{feature}/
# 预期：200
```

### 3a. 微信小程序 / APP 发布（按前端范围选择）

```bash
# 小程序或 APP 项目在客户端根目录提供 devflow-client.json。
# build/test/release 命令必须是可重复执行的真实命令，而非文字结论。
$ bash scripts/client-adapter.sh build mini-program <client-dir> --strict
$ bash scripts/client-adapter.sh test mini-program <client-dir> --strict
# 或
$ bash scripts/client-adapter.sh build app <client-dir> --strict
$ bash scripts/client-adapter.sh test app <client-dir> --strict
```

**发布证据：**

| 平台 | P7 必备证据 |
|------|-------------|
| 微信小程序 | 预览/上传版本号、提审或灰度记录、真机/模拟器关键旅程截图或报告 |
| APP | 构建产物版本号与校验和、测试包/商店渠道记录、模拟器或真机关键旅程报告 |

### 4. 配置更新

```bash

```

## 回滚方案

### 自动回滚触发条件

- [ ] 健康检查失败持续 > 5 分钟
- [ ] 错误率 > 1%
- [ ] P0 问题导致功能不可用

### 回滚步骤

```bash
# 1. 停止部署
$ kubectl rollout undo deployment/org-service

# 2. 验证回滚
$ curl -sS "http://localhost:$PORT/actuator/health"

# 3. 通知相关人员
```

### 数据库回滚

```bash
# Flyway 回滚（慎用）
$ flyway -url=jdbc:postgresql://... undo
```
