## Prometheus 指标

### 业务指标

| 指标名称 | 类型 | 描述 | 单位 |
|----------|------|------|------|
| {feature}_request_total | Counter | 请求总数 | 次 |
| {feature}_request_duration_seconds | Histogram | 请求耗时 | 秒 |
| {feature}_error_total | Counter | 错误总数 | 次 |
| {feature}_active_users | Gauge | 在线用户数 | 人 |

### 示例配置

```java
// 1. 引入 micrometer
private final MeterRegistry meterRegistry;

// 2. 记录指标
meterRegistry.counter("{feature}_request_total", "operation", operation).increment();
meterRegistry.timer("{feature}_request_duration_seconds", "operation", operation)
    .record(Duration.ofMillis(elapsedMs));
```

### 验证命令

```bash
curl -sS "http://localhost:${PORT}/actuator/prometheus" | grep "{feature}"
```

## 告警规则

### P0 告警（立即处理）

| 告警名称 | 条件 | 持续时间 | 通知方式 |
|----------|------|----------|----------|
| 服务不可用 | up == 0 | 1m | 电话 + 短信 |
| 错误率飙升 | error_rate > 5% | 5m | 电话 + 短信 |
| 响应超时 | p95_latency > 5s | 5m | 短信 |

### P1 告警（尽快处理）

| 告警名称 | 条件 | 持续时间 | 通知方式 |
|----------|------|----------|----------|
| 响应慢 | p95_latency > 2s | 10m | 钉钉 |
| 错误率上升 | error_rate > 1% | 10m | 钉钉 |

### 告警配置示例

```yaml
# prometheus/rules/{feature}-alerts.yml
groups:
  - name: {feature}
    rules:
      - alert: {Feature}HighErrorRate
        expr: rate({feature}_error_total[5m]) / rate({feature}_request_total[5m]) > 0.05
        for: 5m
        labels:
          severity: critical
        annotations:
          summary: "{FeatureName} 错误率过高"
          description: "错误率 {{ $value | humanizePercentage }} 超过 5%"
```

## 日志配置

### Logback 配置

```xml
<!-- logback-spring.xml -->
<appender name="JSON" class="ch.qos.logback.core.ConsoleAppender">
    <encoder class="net.logstash.logback.encoder.LogstashEncoder">
        <includeMdcKeyName>traceId</includeMdcKeyName>
        <includeMdcKeyName>userId</includeMdcKeyName>
        <customFields>{"service":"{feature}"}</customFields>
    </encoder>
</appender>

<!-- 业务日志级别 -->
<logger name="com.xycloud.{feature}" level="INFO" additivity="false">
    <appender-ref ref="JSON"/>
</logger>
```

### 日志规范

| 场景 | 级别 | 必须包含字段 |
|------|------|-------------|
| 关键业务操作 | INFO | traceId, userId, operation, result |
| 参数校验失败 | WARN | traceId, userId, params, error |
| 系统异常 | ERROR | traceId, userId, exception, stackTrace |
| 调试信息 | DEBUG | traceId, userId, operation, details |
