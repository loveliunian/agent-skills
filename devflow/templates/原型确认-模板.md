# 原型确认 - {feature_name}

## 字段要点（正本见 schema）

| 字段 | 约束 |
|------|------|
| prototype_refs[] | 原型文件引用（`docs/原型/…`）；工作区反查必须实存 |
| kufs[] | ≥3 条关键用户旅程；id 唯一（KUF-1..N）；每条含 journey 与 walkthrough 走查记录、result 结论 |
| po_conclusion | PO 明确结论；含未决/消极表述会被校验拦截 |
| conclusion_passed | false 不签发 P2b 收据 |
| signoffs[] | 角色/姓名/日期 |

## 渲染结构（产物章节正本）

- 原型文件（prototype_refs 逐条）
- 关键用户旅程 walkthrough（KUF ≥3，逐条走查）
- PO 结论
- 签字确认

## 通过条件

- 管线校验通过并渲染落盘；`p2b_demo_gate.sh` 通过（结论通过 + 签字齐全）。
