# 详细设计模板路由器

> 模板 ID：`详细设计-模板`（路由器）；模板版本：`{{template_version}}`（写产物时以被选用模板的 frontmatter 为准）
> 本文件不再内嵌任何版本的模板正文（v0.1 目录版 / v0.2 摘要版已废弃删除）。
> 直接生成产物时，把对应模板全文复制为起点，不要复制本路由器。

## 模式选择

| 模式 | 判定条件 | 模板 | Gate（s2_design_coverage_gate.sh） |
|------|----------|------|------|
| **单体**（默认） | 模块数 < 5 且无强跨服务依赖 | `详细设计-完整版-模板.md` | `--mode=monolith` |
| **总分-总文档** | 模块数 ≥ 5 / 跨服务依赖强 / 多团队并行 | `详细设计-总分总文档-模板.md` | `--mode=total` |
| **总分-分文档** | 总分模式下每个模块一份 | `详细设计-总分分文档-模板.md` | `--mode=sub` |

## 硬性规则

1. 产物头部必须写所复用模板的**精确 ID 与版本**（`> 模板 ID：`…`` / `> 模板版本：`…``），Gate 按此校验，任意字符串不通过。
2. 产物必须包含五个语义锚点：`data-model` / `api-contracts` / `business-rules` / `acceptance-traceability` / `implementation-handoff`（章节号仅用于展示，锚点是 /plan、/build 与 Gate 的定位正本）。
3. 追溯矩阵逐列非空：PRD锚点(#) / 页面§ / 接口§ / 数据§ / 规则(§或R编号) / 测试用例(TC-) / 状态 COMPLETE。
4. 详设必须逐条引用 P0 冻结的 `constraint_id`（技术硬约束）。
5. §12.1 成熟组件复用清单、§12.2 公共服务与公共组件抽取登记、§13 命名规范、§2.3 设计决策记录（DDR）、§14 实现交接为必含章节（完整版）。

## 调用方式

```bash
# 单体
bash "$SKILL_ROOT/scripts/s2_design_coverage_gate.sh" docs/详细设计/<feature>-详细设计.md docs/需求/<feature>-验收点.md --mode=monolith
# 总分总文档 / 分文档
bash "$SKILL_ROOT/scripts/s2_design_coverage_gate.sh" <design.md> <criteria.md> --mode=total   # 或 --mode=sub
```
