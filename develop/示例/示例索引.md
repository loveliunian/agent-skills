# 示例索引

本目录的示例用一个虚构的“任务提醒”功能串起需求、验收、设计评审、开发、测试和复盘，便于观察每种文档填写后的效果。

维护约定：新增、修改或删除 JSON 契约、JSON/Markdown 模板时，同步更新所有受影响的示例和本索引；没有对应示例时补充一个。示例要反映当前字段、章节、约束和追溯关系。

示例只演示内容组织和追溯关系。项目名称、需求、路径、代码定位、测试结果、来源 ID 和哈希均为虚构，不是可复用的项目事实或运行证据；实际使用时应替换为真实资料，并重新扫描、复核和执行测试。
